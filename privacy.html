NONOKEN Drive Sync｜制定：2026年10月9日

1. 利用目的

本アプリは、開発者本人がGoogle Driveへゲーム制作のビルド成果物を自動転送するためだけに使用する、個人用のOAuthクライアントです。第三者に対してアプリの利用機能を提供しません。

2. アクセス権限と使用するデータ

Google Driveの読み取り・書き込み・管理を可能にするOAuthスコープ（https://www.googleapis.com/auth/drive）を要求します。この権限はDrive内の全ファイルへのアクセスを技術的に許容します。

現在の自動転送処理では、開発者のGoogle Drive内の NONOKEN STUDIO/build/ を保存先に指定し、ビルド成果物をアップロードまたは同名ファイルで更新します。認証やフォルダ参照のためのメタデータ取得が行われる場合があります。他のファイルを収集・配布する目的では使用しません。

3. 認証情報と保存

OAuthクライアント情報とアクセストークン・更新トークンはrcloneの設定に含まれます。自動化用の設定はGitHub Actionsの暗号化されたリポジトリSecretに登録され、転送の実行時にGitHub Actionsの実行環境で使用されます。公開リポジトリやこのWebサイトには認証情報を掲載しません。

4. 外部サービスとのデータのやり取り

ファイル転送にはGoogle Drive、処理の自動実行にはGitHub Actions、サイトの配信にはGitHub Pagesを使用します。これらの事業者は各自の規約・プライバシーポリシーに従い、必要なサービスデータやアクセスログを処理する場合があります。

開発者は本アプリを通じて取得したGoogleユーザーデータを販売せず、広告配信や第三者へのデータ提供にも利用しません。

5. 保存期間とアクセス停止

転送された成果物は、所有者がGoogle Driveから削除するまで保存されます。GitHub Actionsのジョブ実行環境は一時的です。Googleアカウントのセキュリティ設定からアプリのアクセス権を取り消すことで、新たなDriveアクセスを停止できます。GitHub ActionsのSecret削除でも自動転送を停止できます。

6. 連絡先・改定

運用者：NONOKEN STUDIO（個人運用）
連絡先：GitHubプロフィール

Privacy Policy — English Summary

NONOKEN Drive Sync is a private-use OAuth client operated by NONOKEN STUDIO. It transfers game build artifacts from GitHub Actions to the owner's Google Drive through rclone.

It requests the full Google Drive OAuth scope, which technically permits access to all Drive files. The configured automation targets NONOKEN STUDIO/build/ for uploads and updates. OAuth credentials are stored in a private rclone configuration and in GitHub Actions encrypted secrets, never on this website. Google Drive and GitHub process the relevant service data. The operator does not sell Google user data or use it for advertising. Access can be revoked through Google Account settings.
